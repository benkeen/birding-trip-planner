# Birding Trip Planner - Development Guidelines

## UI Framework

**Always use Material UI (MUI) for all React components and styling.**

- Use components from `@mui/material` for all UI elements
- Use `@mui/icons-material` for icons
- Leverage MUI's `sx` prop for component-level styling
- Ensure consistent theming and appearance across all pages
- All pages should follow the same design system (see LoginPage.tsx as reference)

## Key UI Components to Use

- **Layout**: `Box`, `Container`, `Stack`, `Grid`
- **Tables**: `Table`, `TableHead`, `TableBody`, `TableRow`, `TableCell`
- **Forms**: `TextField`, `Button`, `Select`, `Checkbox`
- **Navigation**: `Tabs`, `TabPanel`
- **Display**: `Typography`, `Card`, `Paper`, `Alert`
- **Icons**: Components from `@mui/icons-material`

## Styling Approach

- Prefer MUI's `sx` prop over CSS files
- Use MUI theme values for colors, spacing, and typography
- Keep component-specific styles close to the component definition
- CSS files should only be used for global styles or animations
